This guide gives an in depth description on what has changed compared to the 0.\+x release series.

Many of these changes adjusted automatically by the {\ttfamily lemon-\/0.\+x-\/to-\/1.\+x.\+sh} tool. Those requiring manual update are typeset {\bfseries{boldface}}.\hypertarget{migration_migration-graph}{}\doxysection{Graph Related Name Changes}\label{migration_migration-graph}

\begin{DoxyItemize}
\item Directed graphs are called {\ttfamily Digraph} and they have {\ttfamily Arc}s (instead of {\ttfamily Edge}s), while undirected graphs are called {\ttfamily Graph} (instead of {\ttfamily UGraph}) and they have {\ttfamily Edge}s (instead of {\ttfamily UEdge}s). These changes reflected thoroughly everywhere in the library. Namely,
\begin{DoxyItemize}
\item {\ttfamily Graph} -\/$>$ {\ttfamily Digraph} 
\begin{DoxyItemize}
\item {\ttfamily List\+Graph} -\/$>$ {\ttfamily List\+Digraph}, {\ttfamily Smart\+Graph} -\/$>$ {\ttfamily Smart\+Digraph} etc.
\end{DoxyItemize}
\item {\ttfamily UGraph} -\/$>$ {\ttfamily Graph} 
\begin{DoxyItemize}
\item {\ttfamily List\+UGraph} -\/$>$ {\ttfamily List\+Graph}, {\ttfamily Smart\+UGraph} -\/$>$ {\ttfamily Smart\+Graph} etc.
\end{DoxyItemize}
\item {\ttfamily Edge} -\/$>$ {\ttfamily Arc}, {\ttfamily UEdge} -\/$>$ {\ttfamily Edge} 
\item {\ttfamily Edge\+Map} -\/$>$ {\ttfamily Arc\+Map}, {\ttfamily UEdge\+Map} -\/$>$ {\ttfamily Edge\+Map} 
\item {\ttfamily Edge\+It} -\/$>$ {\ttfamily Arc\+It}, {\ttfamily UEdge\+It} -\/$>$ {\ttfamily Edge\+It} 
\item Class names and function names containing the words {\ttfamily graph}, {\ttfamily ugraph}, {\itshape edge} or {\itshape arc} should also be updated.
\end{DoxyItemize}
\item {\bfseries{The two endpoints of an ({\itshape undirected}) {\ttfamily Edge} can be obtained by the {\ttfamily u()} and {\ttfamily v()} member function of the graph (instead of {\ttfamily source()} and {\ttfamily target()}). This change must be done by hand.}} ~\newline
 Of course, you can still use {\ttfamily source()} and {\ttfamily target()} for {\ttfamily Arc}s (directed edges).
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
{\bfseries{The {\ttfamily lemon-\/0.\+x-\/to-\/1.\+x.\+sh} script replaces the words {\ttfamily graph}, {\ttfamily ugraph}, {\ttfamily edge} and {\ttfamily uedge} in your own identifiers and in strings, comments etc. as well as in all LEMON specific identifiers. So use the script carefully and make a backup copy of your source files before applying the script to them.}}
\end{DoxyWarning}
\hypertarget{migration_migration-lgf}{}\doxysection{LGF tools}\label{migration_migration-lgf}

\begin{DoxyItemize}
\item The \mbox{\hyperlink{lgf-format}{LGF file format}} has changed, {\ttfamily @nodeset} has changed to {\ttfamily @nodes}, {\ttfamily @edgeset} and {\ttfamily @uedgeset} to {\ttfamily @arcs} or {\ttfamily @edges}, which become completely equivalents. The {\ttfamily @nodes}, {\ttfamily @edges} and {\ttfamily @uedges} sections are removed from the format, the content of them should be the part of {\ttfamily @attributes} section. The data fields in the sections must follow a strict format, they must be either character sequences without whitespaces or quoted strings.
\item The {\ttfamily Lemon\+Reader} and {\ttfamily Lemon\+Writer} core interfaces are no longer available.
\item The implementation of the general section readers and writers has changed they are simple functors now. Beside the old stream based section handling, currently line oriented section reading and writing are also supported. In the section readers the lines must be counted manually. The sections should be read and written with the Section\+Writer and Section\+Reader classes.
\item Instead of the item readers and writers, item converters should be used. The converters are functors, which map the type to std\+::string or std\+::string to the type. The converters for standard containers hasn\textquotesingle{}t yet been implemented in the new LEMON. The converters can return strings in any format, because if it is necessary, the LGF writer and reader will quote and unquote the given value.
\item The Digraph\+Reader and Digraph\+Writer can used similarly to the 0.\+x series, however the {\ttfamily read} or {\ttfamily write} prefix of the member functions are removed.
\item The new LEMON supports the function like interface, the {\ttfamily digraph\+Reader} and {\ttfamily digraph\+Writer} functions are more convenient than using the classes directly.
\end{DoxyItemize}\hypertarget{migration_migration-search}{}\doxysection{BFS, DFS and Dijkstra}\label{migration_migration-search}

\item \mbox{\hyperlink{named-param_named-templ-param}{Named class template parameters}} of {\ttfamily Bfs}, {\ttfamily Dfs}, {\ttfamily Dijkstra}, {\ttfamily Bfs\+Visit}, {\ttfamily Dfs\+Visit} are renamed to start with \char`\"{}\+Set\char`\"{} instead of \char`\"{}\+Def\char`\"{}. Namely,

\end{DoxyItemize}\hypertarget{migration_migration-error}{}\doxysection{Exceptions and Debug tools}\label{migration_migration-error}
{\bfseries{The class hierarchy of exceptions has largely been simplified. Now, only the i/o related tools may throw exceptions. All other exceptions have been replaced with either the {\ttfamily LEMON\+\_\+\+ASSERT} or the {\ttfamily LEMON\+\_\+\+DEBUG} macros.}}

{\bfseries{On the other hand, the parameter order of constructors of the exceptions has been changed. See Io\+Error and Format\+Error for more details.}}\hypertarget{migration_migration-other}{}\doxysection{Others}\label{migration_migration-other}

\begin{DoxyItemize}
\item {\bfseries{The contents of {\ttfamily graph\+\_\+utils.\+h} are moved to {\ttfamily core.\+h} and {\ttfamily maps.\+h}. {\ttfamily core.\+h} is included by all graph types, therefore it usually do not have to be included directly.}}
\item {\bfseries{{\ttfamily path\+\_\+utils.\+h} is merged to {\ttfamily path.\+h}.}}
\item {\bfseries{The semantic of the assignment operations and copy constructors of maps are still under discussion. So, you must copy them by hand (i.\+e. copy each entry one-\/by-\/one)}}
\item {\bfseries{The parameters of the graph copying tools (i.\+e. {\ttfamily Graph\+Copy}, {\ttfamily Digraph\+Copy}) have to be given in the from-\/to order.}}
\item {\ttfamily copy\+Digraph()} and {\ttfamily copy\+Graph()} are renamed to {\ttfamily digraph\+Copy()} and {\ttfamily graph\+Copy()}, respectively.
\item {\bfseries{The interface of Dyn\+Arc\+Look\+Up has changed. It is now the same as of Arc\+Look\+Up and All\+Arc\+Look\+Up}}
