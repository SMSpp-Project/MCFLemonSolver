Algorithms for testing (sub)graph isomorphism. 

This group contains algorithms for finding isomorph copies of a given graph in another one, or simply check whether two graphs are isomorphic.

The formal definition of subgraph isomorphism is as follows.

We are given two graphs, $G_1=(V_1,E_1)$ and $G_2=(V_2,E_2)$. A function $f:V_1\longrightarrow V_2$ is called {\itshape mapping} or {\itshape embedding} if $f(u)\neq f(v)$ whenever $u\neq v$.

The standard {\itshape Subgraph Isomorphism Problem (SIP)} looks for a mapping with the property that whenever $(u,v)\in E_1$, then $(f(u),f(v))\in E_2$.

In case of {\itshape Induced Subgraph Isomorphism Problem (ISIP)} one also requires that if $(u,v)\not\in E_1$, then $(f(u),f(v))\not\in E_2$
