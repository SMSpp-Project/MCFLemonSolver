\hypertarget{coding_style_naming_conv}{}\doxysection{Naming Conventions}\label{coding_style_naming_conv}
In order to make development easier we have made some conventions according to coding style. These include names of types, classes, functions, variables, constants and exceptions. If these conventions are met in one\textquotesingle{}s code then it is easier to read and maintain it. Please comply with these conventions if you want to contribute developing LEMON library.

\begin{DoxyNote}{Note}
When the coding style requires the capitalization of an abbreviation, only the first letter should be upper case.
\end{DoxyNote}

\begin{DoxyCode}{0}
\DoxyCodeLine{XmlReader}

\end{DoxyCode}


\begin{DoxyWarning}{Warning}
In some cases we diverge from these rules. This is primary done because STL uses different naming convention and in certain cases it is beneficial to provide STL compatible interface.
\end{DoxyWarning}
