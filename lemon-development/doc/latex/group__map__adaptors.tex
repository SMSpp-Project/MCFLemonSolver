\hypertarget{group__map__adaptors}{}\doxysection{Map Adaptors}
\label{group__map__adaptors}\index{Map Adaptors@{Map Adaptors}}
Tools to create new maps from existing ones. 

This group contains map adaptors that are used to create \char`\"{}implicit\char`\"{} maps from other maps.

Most of them are read-\/only maps. They can make arithmetic and logical operations between one or two maps (negation, shifting, addition, multiplication, logical \textquotesingle{}and\textquotesingle{}, \textquotesingle{}or\textquotesingle{}, \textquotesingle{}not\textquotesingle{} etc.) or e.\+g. convert a map to another one of different Value type.

The typical usage of this classes is passing implicit maps to algorithms. If a function type algorithm is called then the function type map adaptors can be used comfortable. For example let\textquotesingle{}s see the usage of map adaptors with the {\ttfamily graph\+To\+Eps()} function.

 The {\ttfamily functor\+To\+Map()} function makes an {\ttfamily int} to {\ttfamily Color} map from the {\ttfamily node\+Color()} function. The {\ttfamily compose\+Map()} compose the {\ttfamily degree\+\_\+map} and the previously created map. The composed map is a proper function to get the color of each node.

The usage with class type algorithms is little bit harder. In this case the function type map adaptors can not be used, because the function map adaptors give back temporary objects.
