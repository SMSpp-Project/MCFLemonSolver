\hypertarget{group__tsp}{}\doxysection{Traveling Salesman Problem}
\label{group__tsp}\index{Traveling Salesman Problem@{Traveling Salesman Problem}}
Algorithms for the symmetric traveling salesman problem. 

This group contains basic heuristic algorithms for the symmetric {\itshape traveling} {\itshape salesman} {\itshape problem} (TSP). Given an undirected full graph with a cost map on its edges, the problem is to find a shortest possible tour that visits each node exactly once (i.\+e. the minimum cost Hamiltonian cycle).

These TSP algorithms are intended to be used with a {\itshape metric} {\itshape cost} {\itshape function}, i.\+e. the edge costs should satisfy the triangle inequality. Otherwise the algorithms could yield worse results.

LEMON provides five well-\/known heuristics for solving symmetric TSP\+:
\begin{DoxyItemize}
\item Nearest\+Neighbor\+Tsp Neareast neighbor algorithm
\item Greedy\+Tsp Greedy algorithm
\item Insertion\+Tsp Insertion heuristic (with four selection methods)
\item Christofides\+Tsp Christofides algorithm
\item Opt2\+Tsp 2-\/opt algorithm
\end{DoxyItemize}

Nearest\+Neighbor\+Tsp, Greedy\+Tsp, and Insertion\+Tsp are the fastest solution methods. Furthermore, Insertion\+Tsp is usually quite effective.

Christofides\+Tsp is somewhat slower, but it has the best guaranteed approximation factor\+: 3/2.

Opt2\+Tsp usually provides the best results in practice, but it is the slowest method. It can also be used to improve given tours, for example, the results of other algorithms.
