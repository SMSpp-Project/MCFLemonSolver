\label{group__shortest__path}\index{Shortest Path Algorithms@{Shortest Path Algorithms}}
Algorithms for finding shortest paths. 

This group contains the algorithms for finding shortest paths in digraphs {\bfseries [clrs01algorithms]}.


\begin{DoxyItemize}
\item Dijkstra algorithm for finding shortest paths from a source node when all arc lengths are non-\/negative.
\item Bellman-\/\+Ford algorithm for finding shortest paths from a source node when arc lenghts can be either positive or negative, but the digraph should not contain directed cycles with negative total length.
\item Floyd-\/\+Warshall and Johnson algorithms for solving the {\itshape all-\/pairs} {\itshape shortest} {\itshape paths} {\itshape problem} when arc lenghts can be either positive or negative, but the digraph should not contain directed cycles with negative total length.
\item Suurballe A successive shortest path algorithm for finding arc-\/disjoint paths between two nodes having minimum total length.
